# Profile

**Menu:** Profile · **Address:** `/profile`  
**Who:** Everyone who is signed in.

---

## Why this screen exists

This is **your** login, not the shop. Change the name shown as “Welcome back, …” and optionally your password.

Shop name, GSTIN, and logo are on [Business](business.md), not here.

---

## What you see

**Manage your profile.** Note: **Signed in as** your email (email cannot be changed on this screen).

---

## Fields

| Field | Required | What to type |
|-------|----------|----------------|
| **Full name** | Yes | Display name, max 120 characters. |
| **Current password** | Only if you set a new password | Your existing password. |
| **New password** | No | Leave **blank** to keep the old password. If filled: 8–100 characters, and current password is required. |

Click **Save profile**.

Success: **Profile updated.** or **Profile and password updated.** The password boxes clear.

If the current password is wrong, you will see an error. Fix it and save again.

---

## Tips

- Clerks should change the temporary password they chose at invite time if others saw it.
- After a password change, **this browser and other devices** must sign in again with the new password. That is so a leaked old password cannot stay logged in.
